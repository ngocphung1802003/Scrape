chromium-browser

### 4. Bước cuối cùng
1. Truy cập [share.streamlit.io](https://share.streamlit.io/).
2. Chọn Repo `Scrape` của bạn.
3. Chọn file `app.py`.
4. Nhấn **Deploy**.

**Kết quả:** Bạn sẽ có một trang web cực chuyên nghiệp. Mặc dù cấu hình bảng có thể hơi khác một chút so với HTML thuần, nhưng đây là cách duy nhất để code Python của bạn thực sự "sống" được trên môi trường web miễn phí. 

Nếu bạn muốn giữ **100% giao diện HTML** (không dùng bảng của Streamlit), bạn sẽ cần dùng một kỹ thuật nâng cao hơn là `Streamlit Components` để truyền dữ liệu qua lại giữa JavaScript và Python. Bạn có muốn thử mức độ khó đó không?
